# Frontier v6

This branch starts as an exact gameplay copy of the completed v5 release at c16d72fb3dcd1d87fead8c0a0d755c901c7526b5. No v6 gameplay changes have been made.

- `main` remains the live v5 website.
- `codex/v6` is the separate development branch.
- The complete v6 project, including the multiplayer server, Worker backend, admin panel and tests, is in the local `frontier-v6` project folder and full-project ZIP. Backend/admin source is not added to this public frontend repository.
- The original storage keys are retained to preserve exact v5 behavior. A separate hosting origin will naturally keep browser data separate.
- A new v6 domain/backend has not been provisioned yet. The inherited static frontend's multiplayer link still goes to the existing v5 service until v6 hosting is configured.
